# Showcase selection

Included: typed contracts, local CLI orchestration, session and report workflows, explicit confirmation, representative web and API boundaries, synthetic voice and document sidecars, bounded operational scripts, offline tests and a synthetic demonstration.

Excluded: private learner data, private prompts and assets, credentials, full product application, real model weights, deployment secrets and production infrastructure. NestJS, Prisma and BullMQ dependencies are represented by interfaces and process-local adapters. These choices make individual engineering decisions inspectable without claiming full production equivalence.
