## Limits from contributor handoffs

The report-import and pack adapters are narrower than their source services; database token binding and full private assembly are omitted. MCP response contracts are generic, not equivalent to private per-tool output validation. The UI omits detailed evidence panels. Voice uses standard-library synthetic HTTP providers, not streaming or model inference. In-memory stores and queues do not establish distributed or durable guarantees. Test and module line targets were not met uniformly; consult the code for actual coverage.
