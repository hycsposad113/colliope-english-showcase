# Redaction log

The showcase uses relative source references and synthetic learner and session identifiers. Local user-specific paths, real account identifiers and contact details are excluded from the authored demo and documentation. Private credentials and environment files, vault content, private prompt directories, images and audio, caches, logs and test results are excluded from the extraction scope. Internal decision labels and collaboration instructions are not intentionally reproduced in these documents.

The synthetic speech adapters return fixed text and bytes; no real participant recording is included. Source paths in the extraction map identify code locations only. This log describes the intended scope of these files; it is not an independent security audit of concurrently edited files.
